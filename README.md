# Torneo Comercial 2026

Sistema de gestión del **Torneo Comercial 2026** organizado por el Club Atlético Estudiantes de Mercedes.

## Estructura del proyecto (Google Apps Script)

| Archivo | Descripción |
|---------|-------------|
| `Código.gs` | Lógica principal (backend) |
| `Index.html` | Portal público (Inicio, Partidos, Equipos, Goleadores) |
| `Equipo.html` | Página de detalle de un equipo y sus jugadores |

## Cómo usar en Apps Script

1. Abrí tu proyecto de Apps Script vinculado a la planilla.
2. Creá/reemplazá los archivos con el mismo nombre.
3. Pegá el contenido correspondiente.
4. Guardá y generá una **Nueva versión** de la implementación web.
